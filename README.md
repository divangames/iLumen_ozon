# iLumen — карточка в новом свете

[Открыть сайт на GitHub Pages](https://divangames.github.io/iLumen_ozon/)

Публикация выполняется автоматически из папки `dist` после отправки изменений в ветку `main`. Workflow: `.github/workflows/pages.yml`.

Интерактивная презентация по ТЗ.docx, десяти исходным и девяти обновлённым слайдам. Выбранная пользователем композиция: сравнение рядом (визуальный макет B).

Откройте `dist/index.html` напрямую или запустите `python server.py` и перейдите на http://127.0.0.1:4173.

Сайт работает без сборки, внешних библиотек и подключения к сторонним сервисам. Все изображения и шрифты локальные. Есть переключение тем «до / после», галерея с комментариями, четыре сценария света, список сверки и режим показа с клавишами ← → / Escape, свайпами и полноэкранной кнопкой в поддерживающих браузерах.

«До» использует десять исходных слайдов из папки «Карточки/было». Проблема селектора вариантов показана текстом по аудиту, поскольку его скриншот не предоставлен. Новые слайды являются концепцией, характеристики подлежат сверке. Добавлены полный контекст аудита, историческое сравнение конкурентов, примеры названий моделей и план анализа воронки. Публикация на Ozon и фактические изменения карточек не выполнялись.

Шрифты: Manrope (Google Fonts, OFL). Методические рекомендации Unslop: Damir Sokolovsky, https://github.com/heydamir/unslop, CC BY 4.0.

Обновление 10.11.2026: Ozon успешно открыт в обычном Яндекс Браузере. Цены iLumen и трёх конкурентов, описание, ключевые поля и витрина проверены в одной сессии с одним пунктом доставки. Данные и границы проверки — `dist/assets/research/analysis.md`. Новые девять макетов заменили старую галерею; альтернативная обложка выделена для теста.

Полный разбор открывается в оформленном окне с оглавлением, а без JavaScript — на `analysis.html`. После изменения Markdown выполнить `python scripts/build-reading-view.py`: скрипт обновит окно и отдельную страницу. Он также запускается при публикации GitHub Pages. Работает без внешних библиотек и загрузки Markdown в браузере.
